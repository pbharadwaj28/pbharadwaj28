## About Me

👋 I am Prajwal Bharadwaj!

I am an applied computational scientist currently pursuing my Ph.D. in Solid Mechanics at Worcester Polytechnic Institute. My research interest is in the design of mechanical metamaterials for high-performance engineering applications. I am currently exploring the application of generative artificial intelligence in empowering the discovery of mechanical metamaterials with novel dynamic behavior.

## 🚀 Projects
My Github repository contains my software tooling for various projects. Some recent projects include:

1. [Cascade](https://github.com/pbharadwaj28/cascade): This repository contains a custom, GPU-accelerated, hierarchical waterfall segmentation code that is designed to extract physical metrics from optical images of the deformation of cellular solids.
2. [Hierarchical Granular Metamaterials](https://github.com/pbharadwaj28/Hierarchical-Granular-Metamaterials): This repository contains a parametric FEA simulation suite designed to study the high strain-rate behavior of hierarchical granular metamaterials—ordered collections of hollow cylindrical grains embedded with auxetic structures that were designed for withstanding high-strain rate impact.
